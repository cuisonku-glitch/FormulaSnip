识别引擎

默认在本机离线识别。只有选择联网引擎并发起识别，图片才会发送到对应服务。

密钥使用 Windows DPAPI 加密。联网服务的额度和费用由服务商决定。Mathpix Snip 订阅与 API 额度分开。

公式模型：Pix2Text MFR 1.5 · 文字模型：RapidOCR
支持 CPU，无需独立显卡。图文混排可识别中文和公式；复杂多栏、手写和表格请核对结果。

使用提示

  • 单个公式选“公式”；含中文说明的段落选“图文”。
  • 紧贴公式边缘框选，保持清晰，不要把软件工具栏一起截进去。
  • 粘贴到 Word：点“复制到 Word”后直接粘贴，或导出 DOCX。
  • PDF 支持选页导入后识别，不保留原文档的完整排版。
  • 输出为模型识别结果，不保证与 Mathpix 的准确率相同。
