拾式 FormulaSnip 1.1.0 — 更新与测试记录
测试日期：2026-10-13

界面
• 去掉宽侧边栏，改为紧凑的顶部工具栏；默认窗口 900 × 680（原 1220 × 820），最小 620 × 470。
• 截图视图：预览、复制按钮、五种格式、编辑框在默认窗口内一屏显示，不用滚动。
• 工具栏居中显示“第几条 / 共几条”，可翻到上一条、下一条、最早、最新。
• 按钮有悬停、按下、复制成功的动效；识别时显示带扫描动画的截图缩略图。
• 深色模式（右下角切换，或在设置中选择跟随系统）；窗口标题栏随主题变色。
• 记住窗口大小和位置。删除、放弃修改的确认改为界面内对话框。

识别结果
• 离线识别的 LaTeX 自动整理。同一张截图：
  旧：E _ { y ^ { \prime } } = b \sin ( \tau + \delta _ { 0 } \pm \frac { \pi } { 2 } ) \! = \! \pm \mathrm { b } \cos ( \tau \! + \! \delta _ { 0 } )
  新：E_{y^{\prime}}=b \sin \left(\tau+\delta_0 \pm \frac{\pi}{2}\right)=\pm \mathrm{b} \cos(\tau+\delta_0)
  含义不变；预览中分式外的括号会自动变高。可在设置中关闭。
• 旧记录不会自动改写，打开后点“整理”再保存即可。
• 启动后在后台预热公式模型。本机同一张截图的识别时间从 2.1 秒降到 1.0 秒。

其它
• 新增 $ … $ 行内格式；可选择识别后自动复制哪种格式。
• 点击整行格式即可复制；资料库卡片上可直接复制。
• 复制图片、复制到 Word、导出前自动保存未保存的修改。
• 启动后直接显示最近一条记录。
• 快捷键：← → 翻页，Ctrl+C 复制当前 LaTeX，Ctrl+L 资料库，Ctrl+N 新建，Delete 删除。

使用更新
1. 如果旧版还在运行：右键系统托盘里的拾式图标，选择“退出”。
2. 打开同一文件夹里的 FormulaSnip-1.1.0.exe。
3. 保留旁边的 FormulaSnipData 文件夹，历史记录和设置继续使用。
